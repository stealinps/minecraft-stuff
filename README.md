# Minecraft Crafting Tweaks

Enforces armor progression with a strategic Netherite trade-off.

## Progression Chain
- Leather Armor → Chainmail → Iron → Diamond → Netherite (via smithing table) 
- **OR** Golden Armor → Netherite (via crafting table, no enchantment transfer)

## Design Philosophy
- Crafting table is cheaper but **loses enchantments**
- Smithing table is more expensive but **preserves enchantments**
- Provides alternative path
